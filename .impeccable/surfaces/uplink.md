# Surface brief: Uplink (game decks and home page)

THESIS: hack.party is a game show broadcast live from the year 2387, whose graphics
package was cut by hackers from the 16 ANSI terminal colors.

OWN-WORLD: broadcast graphics (lower thirds, station bug, SMPTE color bars) crossed with
terminal culture (ANSI palette, prompts, exit codes, hex). Violet ink, not black; solid
color planes, not neon glow.

STORY: the show boots, cuts between segments with a color-bar wipe, and pays off every
round with a verdict that decrypts on screen.

FIRST VIEWPORT: game decks open on the boot log and the decrypting wordmark; the home page
opens on the wordmark and the next game billed like a show.

FORM: seed: none (unavailable). Code-first build; no image comps.

FINISH: Classic stays pixel-identical; Uplink passes 4.5:1 for text; every animation has a
reduced-motion path; the host never waits on motion.
